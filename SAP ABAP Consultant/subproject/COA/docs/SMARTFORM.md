# Smart Forms Working Guide

Dokumen ini wajib dibaca lengkap sebelum menganalisis, mengubah, meng-import, mengaktifkan, atau menguji SAP Smart Forms pada subproject COA.

Setelah membaca dokumen ini, baca `SMARTFORMS_PATCH.md` secara lengkap. Dokumen tersebut memuat patch XML, cloning style dan border per-cell, pemeriksaan regresi, aktivasi, export ulang, serta verifikasi PDF dari generated function module.

Urutan panduan:

1. `CLAUDE.md`
2. `subproject/COA/docs/COA.md`
3. `subproject/COA/docs/SMARTFORM.md`
4. `subproject/COA/docs/SMARTFORMS_PATCH.md`

Jangan melakukan perubahan SAP sebelum seluruh panduan selesai dibaca dan aturan sandbox, client, rollback, serta transport telah dikonfirmasi.
